3x2 Memory Circuit

Image Credit: Riot Bo Chen | artstation.com/chenbo

Greetings,

My name is Hamza Hashmi, and I will be presenting an overview of one of my side projects—the 3x2 memory circuit. The accompanying images consist of a schematic representation and a visual depiction of the circuit on the breadboard.


This documentation delves into the individual segments of the circuit and examines the schematic, as depicted in the photo. The 3x2 memory circuit functions as a group of registers, with each register serving as a distinct memory location capable of storing a multi-bit binary number. Given its configuration as a 3x2 circuit, it accommodates the storage of 2 bits of data across 3 distinct memory locations.

Background

The 3x2 Memory Circuit is considered a logic circuit which is basically a circuit that can perform logical operations. Such logical operations that are used in the Memory Circuit are the AND, OR and NOT operation.

When 2 signals are passed through a system and an AND operation is applied, the output will be 1 (On) only when both inputs are 1, otherwise the output is 0 (off).
When 2 signals are passed through a system and an OR operation is applied, the output will be 1 (On) when either of the inputs are 1, otherwise the output is 0 (off).
When 1 signal is passed through a system and an NOT operation is applied, the output will be opposite of what is being inputted.

These elements are categorized as combinational circuits, wherein the output is contingent upon the input variables. Additionally, within this circuit, there exists a component whose output depends not only on the input variables but also on the previous state of the circuit. These elements fall under the category of sequential circuits, with the specific component employed in this circuit being the D-FlipFlop. It features an input labeled D, where a value of 0, coupled with a clock pulse through the flip flop, yields an output of 0. Conversely, when the D value is 1 and a clock pulse is applied, the output becomes 1. In the absence of a clock pulse, the output remains unchanged, thus preserving its current state in memory.

Functionality Of Circuit

The 3x2 Memory Circuit is composed of 5 main parts. These parts being the Memory Location Select, Read/Write Circuit, Memory Component, Memory Out and a 2nd Read/Write Circuit, all of which are explained in more detail further below.

By the address bus, there are 2 inputs, and in binary that gives us 4 possible combinations meaning we can have up to 4 locations in memory but I will be only using 3. When both the inputs are 1(11), memory location 11 will be activated. When one input is 1 and the other 0(10), memory location 10 will be activated. And when one input is 0 and the other 1(01), memory location 01 is activated.

If the input is 01, the 01 selector will output a high to an AND gate which is part of a Read/Write circuit. This AND gate is connected to a switch, and when the switch is open, a signal of 0 is sent to an OR gate which reverses the output signal to a 1, sending it to AND in the Read/Write circuit which then sends the signal to 2 D-FlipFlops which ultimately means the circuit is choose memory location 01.

When we want to store data, we give data bit 0 and data bit 1 values, and in this example we will be giving them both values of 1. This is then sent to the D-FlipFlops input called D, which is then clocked and the same value is moved to the output of the D-FlipFlops leaving us with 11 sitting at the output.

No use in storing if we can't retrieve it later, so we have to read what's in memory. Since memory location 10 has been chosen, the 1st and 4th AND gate from the top in the Memory Out circuit are receiving an input. And since we are receiving a value of 11 from the D-FlipFlops, the 1st and 4th AND gate from the top output a high.

Now to read the memory location, we close the switch (which is connected to a +ve) giving us a high which inputs into the 1st and 4th AND gate from the top in the Read/Write circuit.

The 2 sets of 2 OR gates will read the output, which are both high and thus outputting a high to the LED, turning both the LEDs on, signifying that the data stored in memory location 01 were 2 1’s.

Components in Detail

  1. Address Bus/Memory Location Select

    The address bus determines the storage location in one of the three memory locations, represented by AND gates. The address leads A1 and A0 dictate the chosen location, with specific conditions for each. In the illustrated breadboard photo, we observe the storage of 2 bits of data in memory location 10 (location 2).

  2. Switch

    Positioned to the right of the address bus, a switch (represented by a loose black wire) connected to a NOT gate influences the read/write circuit. The read/write circuit is triggered by the state of the switch, and a clock pulse occurs when the switch is open.

  3. Read/Write Circuit

    Right above the address bus is the Read/Write Circuit. The AND gates are connected to the clock of the D-FlipFlops.

  4. Memory Component

    Positioned above the Read/Write section, the memory employs D-FlipFlops. Comprising six D-FlipFlops, this section functions based on clock pulses and data input, ensuring data retention or updating. If the Data input lead is 1, pulse the cloak and output is 1. If the Data input lead is 0, and cloak is not pulsed, output would still be 1 which is considered to be retained in memory.

  5. Memory Out

    To the right of the memory, we find the memory out, indicating the current state of the memory.

  6. Second Read/Write Circuit

    Adjacent to the memory out, the second read/write circuit facilitates the reading of stored data.

  7. LED Display

    To the right of the second read/write circuit, LEDs are connected to an OR IC. These LEDs, red and green, illuminate based on the stored data in Bit 0 and Bit 1, respectively.

  8. Power Indicator

    Additionally, an auxiliary component, the power indicator circuit, has been incorporated to monitor the power supply status from the battery. (Top right corner of breadboard)


Live explanation and demonstration of the circuit:

The aim of this project is to highlight the remarkable capacity of modern storage devices, such as a 128 GB USB, which can hold 128,000,000,000 bits of data within a compact space. In contrast, this project achieves data storage using only 2 bits across 2 breadboards. Reflecting on this comparison showcases the incredible capabilities of modern technology.
