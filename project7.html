Components in Detail

  1. Register

    The processor consists of several regisotrs which are either 1-bit or 32-bit. Purpose of a 32-bit register is to store and manipulate 32 bits of binary information.

    Both registers update at each clock pulse. When the ‘ld’ bit is high, the input bit ‘d’ is allowed to pass through to the output bit ‘Q’. If the ‘clr’ bit is high at any clock pulse, the output will be low. The only difference is that the 32-bit register allows for 32-bit inputs, represented in decimal in this simulation. In the 32-bit simulation, different input values are used to demonstrate the function of the register.

  2. Program Counter (PC)

    The program counter is a another key component in the processor. It is comprised of a 32-bit register, a 4-bit adder and a 2-to-1 multiplexer.

    The 32-bit register has 5 signals: input/(D), clk, enable input, reset input, output(Q). The register is basically a flip flop, it maintains the input value until it hits the +ve edge of a clcok, output challenges to whatever the input value is at that time. When enable becomes 1 for the 1st time, and data is 1, output (Q) will be 1 as well. output will stay 1 even if the input changes until the reset signal is high, where at this point output is going to change back to 0. This is what is called a +ve edge triggered register, only changes at +ve edge of the clock.

    The 4-bit Adder has an input A and an input B that is equal to a vlaue of 4, an input of Cin, an output Cout and has an output S. This component simply takes the input bit ‘A’ and adds 4 bits to it at the output ‘B’.

    The 2-to-1 multiplexer has 3 inputs (w0, w1 and S), and 1 output. If S is 1, w0 will be selected and if S is 0, w1 will be selected.

    All thats left to do is to take the 3 above components and combine them together to get a program counter. The program counter has d which is input and a has constant value of 5 and q which is output. Clr - when set to high, reset the output value/turns output to 0 and when low, output is unchanged. Clk - which is a normal clock pulse. ld controls whether the output can pass through the 32-bit register component, if high allows output to pass and if low, does not allow output to pass through. And finally inc, whic is the 4-bit adder, if high, then 4 bit adder is active and if low, the adder is off, and the input is sent to the output.

  3. Arithmatic Logic Unit (ALU)

    The 32-bit Arithmatic Logic Unit does all the operations in the processor. It is basically a multiplexer with an op_code that decides what operation to use. The ALU has an two 32-bit inputs A and B, a 3-bit input input op_code and for outputs has a Carry, has a zero flag and a 32-bit result. The ALU can perform upto 6 different operations. 00 is AND when neg select is 0, 01 is OR when neg select is 0, 10 is add when neg select is 0, 10 is sub when neg select is 1, 00 is shift left when neg select 1 (shift left multiplies by 2 in logic), finally 01 is shift right when neg select 1.

    Since the ALU is is 32-bit, we will also be needing a 32-bit adder which can be made using multiple 1-bit adders. 32 bit adder needs 2 16 bit adders, 16 bit adder needs 4 4 bit adders, 4 bit adder needs 4 1 bit adders, and the 1 bit adder just needs its own code.

    In the simulation above, we set input A=7 and input B=6 and perform operations on them based on the speific op code. 000 converts 6 and 7 to binary and perofrms AND operation where then the result comes out in decimal. 001 converts 6 and 7 to binary and perofrms OR operation where then the result comes out in decimal. 010 converts 6 and 7 to binary and perofrms the addition operation where then the result comes out in decimal. 011 copies the B input to the output. 100 converts 7 to binary(0111) and perofrms Shift Left operation(1110) where then the result comes out in decimal(14). 101 converts 7 to binary(0111) and perofrms Shift Left operation(0011) where then the result comes out in decimal(3). 110 converts 6 and 7 to binary and perofrms the subtraction operation where then the result comes out in decimal. 111 copies the A input to the output.
