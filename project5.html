Greetings,

  1. Introduction

    This project is related closely to Microprocessor Systems subject, which focuses on the design and implementation of small microprocessor-based systems, with an emphasis on embedded system hardware and software design. The objective was to program the EEBOT mobile robot with a navigation system capable of autonomously navigating a maze and adapting to obstacles.

  2. Project Overview

    The primary goal was to develop a program to guide the EEBOT robot through a maze. The robot needed to navigate the maze, reverse, and back its way out. Additionally, the robot could be programmed to learn the maze and navigate it without errors on subsequent attempts.

    This project as well aimed to design, install, and test a program for the EEBOT robot to follow a simple roaming pattern. The pattern included driving in a straight line, stopping and turning after a set interval if no obstacles were encountered, and executing a back-and-turn maneuver when encountering obstacles.

  3. Components of the Project

    Programming the I/O Devices
