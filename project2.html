Line Following Robot

Image Credit: AGuo | artstation.com/a_guo

Greetings,

I am Hamza Hashmi, and I am excited to present an overview of another one of my side projects—the line-following robot. The primary goal of this undertaking was to design a robot capable of following lines. Components such as the PIC24F32KA302 microcontroller, a customized breadboard circuit, PICkit3 microcontroller, the MPLab X programming software, and the integration of highly sensitive color sensors were used to accomplish the goal of following a path from start to finish and back again.


Key Components:

  1. PIC24F32KA302 Microcontroller Connection Diagram

    RA0 to RA4 are connect to ground via 2.2k Resistor. This is called pulling down the signal to ground to make sure there is no stray noise going into the circuit. RB6 to RB13 are connect to LEDs (using 8 LEDs).

  2. Breadboard Circuit

  3. PICkit3 Microcontroller Programmer Connection Diagram

    Pin 1 is connect to MCLR on the PIC24F32KA302. Pin 2 is connected to VDD_2 on the PIC24F32KA302. Pin 3 is conneted to VSS_2 on the PIC24F32KA302. Pin 4 is connected to RB0 on the PIC24F32KA302. Pin 5 is connected to RB1 on the PIC24F32KA302. Pin 6 is not connected to anyhting.

  4. Robot's Chassis

  5. MPLab X Code

    TRISA - assign a port to be I/P=1 or O/P=0. TRISA=0xffff writes to an entire registor which is 16 bits. Color sensors have values of 0 or 1. If they read value 0, they are reading color black, if the sensor is reading value 1, the sensors are reading color white. Input 0 is left color sensor, and Input 1 is right color sensor.

  6. 4x4 Playing Field Dimensions
